# 학습 콘텐츠 출처 기록

이 저장소와 배포 사이트는 **공개**다. 여기에 들어간 자료는 그대로 재배포되므로, 자료마다 어디서 왔고 어떻게 만들었는지를 남긴다.
새 자료를 넣을 때도 이 표에 한 줄을 더한다.

## 원칙

- **넣을 수 있는 것**: 직접 쓴 설명 · 문제 · 해설, 사실 정보(어느 회차에 어떤 개념이 나왔는지), 라이선스가 허락하는 자료(출처 · 조건 표기)
- **넣지 않는 것**: 교재 · 블로그 · 복원 기출의 문장 · 코드 · 해설 복사, 교재의 구성 · 번호 체계를 따른 정리, 로그인 자료 · PDF
- 공개된 글이라도 라이선스가 없으면 열람만 한다. GitHub 의 라이선스도 올린 사람이 직접 쓴 내용일 때만 유효하다
- 기출 개념을 다룰 때는 **같은 개념을 다른 코드 · 수치 · 문장으로 새로 만들고**, 코드는 실제로 실행해 답을 검증한다
