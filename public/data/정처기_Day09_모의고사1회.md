### 문제 1. 다음 C 프로그램의 출력 결과를 쓰시오. (5점)

```c
#include <stdio.h>
int main() {
    int a[] = {3, 6, 9, 12, 15};
    int *p = a + 1;
    printf("%d ", *(p + 2));
    printf("%d ", *p * 2);
    p += 2;
    printf("%d ", p[-1] + p[1]);
    printf("%d\n", (int)(p - a));
    return 0;
}
```

답:

<details><summary>정답 확인</summary>

**정답: `12 12 24 3`**

```
p = a + 1 → p 는 a[1](6)
*(p + 2)       = a[3] = 12
*p * 2         = 6 * 2 = 12   (*p 가 먼저, 그다음 곱셈)
p += 2         → p 는 a[3]
p[-1] + p[1]   = a[2] + a[4] = 9 + 15 = 24
p - a          = 포인터 사이의 원소 개수 = 3
```

</details>

```java
public class Main {
    public static void main(String[] args) {

```

답:

<details><summary>정답 확인</summary>

```

```

```
area() 는 오버라이딩 → 실제 객체 Square 의 area() = 4*4 = "16"
s.name        → 변수 타입 Shape 기준 = "shape"
((Square)s).name → Square 타입으로 보면 "square"
핵심: 메서드는 실제 객체, 필드는 변수(참조) 타입 기준
```

### 문제 17. 다음 C 프로그램의 출력 결과를 쓰시오. (5점)

```c
#include <stdio.h>
void swap1(int a, int b) { int t = a; a = b; b = t; }
void swap2(int *a, int *b) { int t = *a; *a = *b; *b = t; }
int main() {
    int x = 3, y = 8;
    swap1(x, y);
    printf("%d %d\n", x, y);
    swap2(&x, &y);
    printf("%d %d\n", x, y);
    swap2(&x, &x);
    printf("%d\n", x - y);
    return 0;
}
```

답:

<details><summary>정답 확인</summary>

**정답:**

```
3 8
8 3
5
```

```
swap1 은 값의 복사본만 바꾼다 → x, y 그대로 3 8
swap2 는 주소를 받아 원본을 바꾼다 → 8 3
swap2(&x, &x): a 와 b 가 같은 x → t=8, x=8, x=8 → 변화 없음
x - y = 8 - 3 = 5
```

</details>

### 문제 19. 다음 Java 프로그램의 출력 결과를 쓰시오. (5점)

```java
class Account {
    int balance = 100;
    int fee() { return 10; }
    int withdraw(int amt) {
        balance -= amt + fee();
        return balance;
    }
}
class Premium extends Account {
    int fee() { return super.fee() / 2; }
    int withdraw(int amt) { return super.withdraw(amt) + 1; }
}
public class Main {
    public static void main(String[] args) {
        Account acc = new Premium();
        System.out.println(acc.withdraw(30));
        System.out.println(acc.withdraw(20) + acc.balance);
    }
}
```

답:

<details><summary>정답 확인</summary>

**정답:**

```
66
81
```

```
acc.withdraw(30) → Premium.withdraw → super.withdraw(30)
  Account.withdraw 안의 fee() 도 실제 객체 Premium 의 것 = 10 / 2 = 5
  balance = 100 - (30 + 5) = 65 → 65 + 1 = 66
acc.withdraw(20) → balance = 65 - 25 = 40 → 40 + 1 = 41
41 + acc.balance(40) = 81
```

</details>
