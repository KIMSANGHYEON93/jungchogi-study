<details><summary>정답</summary>

**데이터 마이닝(Data Mining)**

### Y002. 관계대수와 관계해석의 차이를 쓰시오.

<details><summary>정답</summary>

- **관계대수**: 원하는 결과를 얻는 **방법(절차)** 을 연산자 순서로 기술 — 절차적 언어
- **관계해석**: 원하는 결과가 **무엇인지** 만 술어(predicate)로 기술 — 비절차적 언어
- 두 방식의 표현 능력은 같다

</details>

### Y003. 로그 기반 회복에서 REDO 와 UNDO 를 하는 경우를 각각 쓰시오.

<details><summary>정답</summary>

- **UNDO**: 로그에 **시작은 있지만 COMMIT 이 없는** 트랜잭션 — 변경을 취소

</details>

### Y004. 성적 테이블을 학년 오름차순, 같은 학년 안에서는 점수 내림차순으로 조회하는 ORDER BY 절을 쓰시오.

<details><summary>정답</summary>


- ASC 는 생략할 수 있다(기본값). 앞에 적은 열이 먼저 정렬 기준이 된다

### Y005. 사원 테이블에서 사번이 1001 인 사원의 부서를 '기획'으로, 급여를 10% 올리는 SQL 문을 쓰시오.

<details><summary>정답</summary>

### Y006. 학생(학번, 이름) 테이블에 (2024001, '홍길동')을 넣는 SQL 문과, 신입생 테이블의 행을 통째로 학생 테이블에 복사하는 SQL 문을 쓰시오.

### Y007. 학생 테이블과 수강 테이블을 학번으로 내부 조인하는 SQL 의 FROM 절을 JOIN ... ON 으로 쓰시오.

<details><summary>정답</summary>


### Y008. 조인 조건에 따른 조인 종류를 쓰시오: (1) =, <, > 등 비교 연산자로 조인 (2) = 로만 조인 (3) = 로 조인하고 중복 열을 하나만 남김

<details><summary>정답</summary>

- (1) **세타 조인(θ-Join)**
- (2) **동등 조인(Equi Join)**
- (3) **자연 조인(Natural Join)**

</details>

### Y009. 행이 4개인 테이블 A 와 행이 3개인 테이블 B 를 CROSS JOIN 하면 결과 행은 몇 개인가?

<details><summary>정답</summary>

**12개** — 교차 조인(카티션 곱)은 행 수가 곱해진다(4 × 3). 열(차수)은 더해진다

</details>

### Y010. LEFT OUTER JOIN, RIGHT OUTER JOIN, FULL OUTER JOIN 의 차이를 쓰시오.

<details><summary>정답</summary>

- **LEFT**: 왼쪽 테이블의 행은 짝이 없어도 모두 남기고, 오른쪽 열은 NULL
- **RIGHT**: 오른쪽 테이블의 행을 모두 남긴다
- **FULL**: 양쪽의 짝 없는 행을 모두 남긴다

</details>

### Y011. 무결성 제약조건 4가지를 쓰고 설명하시오: 개체, 참조, 도메인, 사용자 정의

<details><summary>정답</summary>

- **개체 무결성**: 기본키는 NULL · 중복 불가
- **참조 무결성**: 외래키는 참조하는 테이블의 기본키 값이거나 NULL
- **도메인 무결성**: 속성 값은 정해진 도메인(타입 · 범위)에 속해야 한다
- **사용자 정의 무결성**: 업무 규칙에 맞는 값만 허용

</details>

### Y012. 선수 테이블의 팀코드가 팀 테이블의 팀코드를 참조하고, 팀이 삭제되면 소속 선수도 함께 삭제되도록 하는 제약조건을 쓰시오.

<details><summary>정답</summary>

```sql
FOREIGN KEY (팀코드) REFERENCES 팀(팀코드) ON DELETE CASCADE
```

- 다른 옵션: `SET NULL`(NULL 로 바꿈), `RESTRICT` / `NO ACTION`(참조 중이면 삭제 거부)

</details>

### Y013. 성별 열에 'M' 또는 'F' 만 들어가도록 하는 제약조건을 쓰시오.

<details><summary>정답</summary>

```sql
CHECK (성별 IN ('M', 'F'))
```

- 도메인으로 정의할 때: `CREATE DOMAIN 성별 CHAR(1) CHECK (VALUE IN ('M', 'F'));`

</details>

### Y014. 사원(이름, 부서, 급여) 테이블이 (가, 개발, 250), (나, 개발, 350), (다, 영업, 400), (라, 영업, 200), (마, 인사, 500) 일 때, `WHERE 부서 = '개발' OR 부서 = '영업' AND 급여 >= 300` 의 결과 행 수를 쓰시오.

<details><summary>정답</summary>

**3개** (가, 나, 다)

- AND 가 OR 보다 먼저 계산된다 → `부서 = '개발' OR (부서 = '영업' AND 급여 >= 300)`
- 개발 2명 + 영업 중 급여 300 이상 1명(다) = 3
- 괄호로 `(부서 = '개발' OR 부서 = '영업') AND 급여 >= 300` 이면 2개(나, 다)

</details>

### Y015. 파일 구조 3가지를 쓰고 특징을 쓰시오: 순차, 색인 순차, 직접

<details><summary>정답</summary>

- **순차 파일**: 레코드를 키 순서대로 저장 — 일괄 처리에 유리, 검색 느림
- **색인 순차 파일(ISAM)**: 순차 파일 + **인덱스** — 순차 · 임의 접근 모두 가능
- **직접 파일**: 해싱으로 계산한 주소에 저장 — 임의 접근이 가장 빠름

</details>

### Y016. E-R 다이어그램에서 개체, 관계, 속성, 기본키 속성을 나타내는 기호를 쓰시오.

### Y038. 자신과 다른 악성코드의 존재를 숨기고 관리자 권한을 유지하게 하는 악성 프로그램 묶음은?

### Y039. "컴퓨터가 감염됐다"는 가짜 경고로 불안하게 만들어 가짜 백신 구매 · 설치를 유도하는 악성 소프트웨어는? 광고를 강제로 띄우는 것(①)과 몰래 정보를 수집하는 것(②)도 쓰시오.

### Y040. 보안 장비 · 시스템의 로그와 이벤트를 모아 연관 분석하고 위협을 실시간으로 탐지하는 통합 보안 관리 솔루션은?

### Y041. 조직의 정보 자산을 지키기 위한 정책 · 조직 · 절차 등 관리 체계를 갖추었는지 인증하는 제도는?

### Y042. 정보보호의 AAA 3요소를 쓰시오.

- **인가(Authorization)**: 무엇을 할 수 있는지 권한 부여
- **계정 관리(Accounting)**: 무엇을 했는지 기록 · 과금

### Y043. 한 번만 쓰고 버리는 비밀번호를 시간 · 횟수에 따라 생성하는 인증 방식은?

**OTP(One-Time Password)**

### Y044. 프로세서 안에 일반 영역과 분리된 보안 영역을 두어 민감한 연산을 따로 실행하는 하드웨어 기반 보안 기술을 무엇이라 하며, ARM 의 대표 구현은?

**TEE(Trusted Execution Environment, 신뢰 실행 환경)** — ARM 의 **TrustZone**

</details>

### Y045. 무선랜 보안 방식을 오래된 순으로 쓰고, WEP 의 키 문제를 보완하려고 패킷마다 키를 바꾸는 프로토콜을 쓰시오.

<details><summary>정답</summary>

- **WEP → WPA → WPA2 → WPA3**
- 패킷마다 키를 바꾸는 프로토콜: **TKIP(Temporal Key Integrity Protocol)** — WPA2 부터는 AES 기반 CCMP

</details>

### Y046. 다음 대칭키 알고리즘을 설명하시오: IDEA, SEED, ARIA

<details><summary>정답</summary>

- **IDEA**: 스위스에서 개발, 64비트 블록 · 128비트 키
- **SEED**: 한국인터넷진흥원(KISA) 개발, 128비트 블록
- **ARIA**: 국가보안연구소 중심 개발, 128비트 블록 · 128/192/256비트 키(AES 와 같은 규격)

</details>

### Y047. 공용 인터넷 위에 암호화 터널을 만들어 사설망처럼 쓰게 하는 기술(①)과, 2계층에서 동작하는 터널링 프로토콜 2가지(②)를 쓰시오.

<details><summary>정답</summary>

- ① **VPN(Virtual Private Network)**
- ② **PPTP, L2TP** (3계층은 IPSec, 4계층 이상은 SSL VPN)

</details>

### Y048. 원격 접속 · 명령 실행 · 파일 전송을 암호화하며 기본 포트 22 를 쓰는 프로토콜은?

<details><summary>정답</summary>

**SSH(Secure Shell)** — 평문 원격 접속인 Telnet(23) 을 대체한다

</details>

### Y049. 패킷 교환 방식 중 연결을 먼저 설정하고 같은 경로로 순서대로 보내는 방식(①)과, 연결 없이 패킷마다 경로를 따로 정하는 방식(②)을 쓰시오.

<details><summary>정답</summary>

- ① **가상 회선(Virtual Circuit) 방식**
- ② **데이터그램(Datagram) 방식**

</details>

### Y050. 53바이트 고정 길이 셀 단위로 전송하는 고속 교환 방식은?

<details><summary>정답</summary>

**ATM(Asynchronous Transfer Mode, 비동기 전송 모드)** — 헤더 5바이트 + 데이터 48바이트

</details>

### Y051. HDLC 프레임의 3가지 종류를 쓰고 각각의 용도를 쓰시오.

<details><summary>정답</summary>

- **정보(I) 프레임**: 사용자 데이터 전송
- **감독(S) 프레임**: 흐름 · 오류 제어(확인 응답 등)
- **비번호(U) 프레임**: 링크 설정 · 해제 등 제어
- 프레임 시작 · 끝은 플래그 01111110

</details>

### Y052. 오류 제어 기법을 설명하시오: 패리티 검사, CRC, 해밍 코드

<details><summary>정답</summary>

- **패리티 검사**: 1의 개수를 짝 · 홀수로 맞춰 1비트 오류 **검출**
- **CRC(순환 중복 검사)**: 다항식으로 나눈 나머지를 붙여 **검출** — 연속 오류(버스트)에 강함
- **해밍 코드**: 여러 패리티 비트로 1비트 오류를 **검출하고 정정**(전진 오류 수정, FEC)
- 검출만 하고 재전송을 요청하면 ARQ(후진 오류 수정)

</details>

### Y053. 거리 벡터 방식으로 홉 수가 가장 적은 경로를 고르며 최대 홉 수가 15인 라우팅 프로토콜은? 링크 상태 방식의 대표 프로토콜도 쓰시오.

<details><summary>정답</summary>

- **RIP(Routing Information Protocol)** — 16홉 이상은 도달 불가로 본다, 30초마다 테이블 교환
- 링크 상태 방식: **OSPF** (다익스트라 알고리즘, 대규모 네트워크)

</details>

### Y054. 기지국 · 유선망 같은 고정 기반 없이 단말끼리 동적으로 망을 이루는 네트워크는?

<details><summary>정답</summary>

**애드혹 네트워크(Ad-hoc Network)** — 재난 현장 · 군사 작전 등에 쓰이고 토폴로지가 수시로 바뀐다

</details>

### Y055. URL `https://www.example.com:8443/board/list?page=2#top` 의 각 부분 이름을 쓰시오.

<details><summary>정답</summary>

- `www.example.com` — **호스트(도메인)**

## F. OS · 기타 — 6문제

### Y056. 프로세스 상태 전이에서 다음 전이의 이름을 쓰시오: (1) 준비 → 실행 (2) 실행 → 준비(할당 시간 끝) (3) 실행 → 대기(입출력 요청) (4) 대기 → 준비(입출력 완료)

<details><summary>정답</summary>

- (1) **디스패치(Dispatch)**
- (2) **타이머 런아웃(Timer Run-out)**
- (3) **블록(Block)**
- (4) **웨이크업(Wake-up)**

</details>

### Y057. 도착 시간 · 실행 시간이 P1(0, 7), P2(2, 4), P3(4, 1), P4(5, 4) 일 때 SRT 스케줄링의 평균 대기 시간을 구하시오.

<details><summary>정답</summary>

**3**

- 0~2 P1 → 2 에 P2(4) 가 P1 남은 5 보다 짧아 선점 → 2~4 P2 → 4 에 P3(1) 이 P2 남은 2 보다 짧아 선점 → 4~5 P3 → 5~7 P2 → 7~11 P4(4) → 11~16 P1(남은 5)
- 대기 = 종료 − 도착 − 실행: P1 16−0−7 = 9, P2 7−2−4 = 1, P3 5−4−1 = 0, P4 11−5−4 = 2
- (9 + 1 + 0 + 2) / 4 = **3**

</details>

### Y058. 도착 시간 · 실행 시간이 P1(0, 5), P2(1, 3), P3(2, 1), P4(3, 2) 이고 시간 할당량이 2 일 때 RR 스케줄링의 평균 대기 시간을 구하시오. (같은 시각에 새로 도착한 프로세스가 할당량을 다 쓴 프로세스보다 먼저 줄을 선다)

<details><summary>정답</summary>

**4.5**

- 실행 순서: P1(0~2) → P2(2~4) → P3(4~5) → P1(5~7) → P4(7~9) → P2(9~10) → P1(10~11)
- 대기 = 종료 − 도착 − 실행: P1 11−0−5 = 6, P2 10−1−3 = 6, P3 5−2−1 = 2, P4 9−3−2 = 4
- (6 + 6 + 2 + 4) / 4 = **4.5**

</details>

### Y059. 디스크 여러 개를 묶는 RAID 의 0, 1, 5 를 설명하시오.

<details><summary>정답</summary>

- **RAID 0**: 데이터를 나눠 여러 디스크에 분산 저장(스트라이핑) — 빠르지만 중복이 없어 하나만 고장 나도 손실
- **RAID 1**: 같은 데이터를 두 디스크에 복사(미러링)
- **RAID 5**: 스트라이핑 + 패리티를 여러 디스크에 분산 — 디스크 1개 고장까지 복구

</details>

### Y064. 리눅스 커널 위에서 동작하며 휴대 기기용 운영체제 · 미들웨어 · 기본 앱을 함께 제공하는 구글의 오픈소스 모바일 플랫폼은? 애플의 모바일 운영체제도 쓰시오.

<details><summary>정답</summary>

- **안드로이드(Android)** — 앱은 주로 Java · Kotlin 으로 개발하고 ART 런타임에서 실행된다
- 애플: **iOS** (Swift · Objective-C)

</details>

### Y065. 객체가 생성될 때 자동으로 호출되어 멤버를 초기화하는 특수 메서드(①)와, 객체가 소멸될 때 호출되는 메서드(②)를 쓰시오. 생성자의 특징도 쓰시오.

<details><summary>정답</summary>

## G. 인터페이스 · 웹 — 4문제

### Y060. 데이터를 태그로 구조화해 표현하는 W3C 표준 마크업 언어로, SGML 을 단순화해 웹에서 쓰기 쉽게 만든 것은?
