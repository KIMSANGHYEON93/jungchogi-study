## PART 1: 포인터 핵심 정리

### 1-1. 포인터 기본 개념

```c
int a = 10;
int *p = &a;    // p는 a의 주소를 저장

printf("%d", a);    // 10      (변수의 값)
printf("%p", &a);   // 0x7fff  (변수의 주소)
printf("%p", p);    // 0x7fff  (포인터가 저장한 주소)
printf("%d", *p);   // 10      (포인터가 가리키는 값 = 역참조)
```

### 1-2. 포인터 연산 핵심 공식

```
p       → 주소값
*p      → 해당 주소의 값 (역참조)
p + 1   → 다음 요소의 주소 (자료형 크기만큼 이동)
*(p+1)  → 다음 요소의 값
&a      → 변수 a의 주소
```

### 1-3. 문자열 포인터 (시험 최빈출!)

```c
char *p = "SEOUL";
// 메모리:  S  E  O  U  L  \0
// 인덱스:  0  1  2  3  4

printf("%s", p);      // SEOUL    (%s: 해당 주소부터 \0까지 출력)
printf("%s", p+3);    // UL       (인덱스 3부터 끝까지)
printf("%c", *p);     // S        (첫 글자)
printf("%c", *(p+3)); // U        (인덱스 3의 글자)
printf("%c", *p+2);   // U        ('S'=83, 83+2=85='U')
```

> **핵심**: `*p+2`는 값에 2를 더함, `*(p+2)`는 주소를 2 이동 후 값을 가져옴

### 1-4. 포인터와 배열의 관계

```c
int arr[] = {10, 20, 30, 40, 50};
int *p = arr;    // 배열명 = 첫 번째 요소의 주소

// 아래는 모두 동일한 결과:
arr[2]    == *(arr+2)   == *(p+2)   == p[2]   // → 30
&arr[2]   == arr+2      == p+2                 // → 30의 주소
```

## PART 2: 배열 핵심 정리

### 2-1. 2차원 배열

```c
int arr[2][3] = {1, 2, 3, 4, 5, 6};

// 메모리 구조:
// arr[0][0]=1  arr[0][1]=2  arr[0][2]=3
// arr[1][0]=4  arr[1][1]=5  arr[1][2]=6

printf("%d", arr[1][2]);    // 6
printf("%d", *(arr[0]+1));  // 2  (arr[0]은 1행의 시작주소)
```

### 2-2. 배열 포인터 vs 포인터 배열

```c
int (*p)[3];    // 배열 포인터: 3개짜리 배열을 가리키는 포인터
int *p[3];      // 포인터 배열: 포인터 3개를 저장하는 배열
```

## PART 3: 구조체 핵심 정리

### 3-1. 구조체 선언과 접근

```c
struct Student {
    char name[20];
    int score;
};

struct Student s1 = {"Kim", 90};
struct Student *p = &s1;

// 접근 방법 2가지:
printf("%s", s1.name);    // 변수로 접근: .  (dot)
printf("%d", p->score);   // 포인터로 접근: -> (arrow)
```

> **시험 핵심**: `.` vs `->` 구분!
> - 구조체 변수: `변수.멤버`
> - 구조체 포인터: `포인터->멤버`

### 3-2. 구조체 배열

```c
struct Student st[3] = {
    {"데이터1", 95, 88},
    {"데이터2", 84, 91},
    {"데이터3", 86, 75}
};
struct Student *p = &st[0];

// p     → st[0]
// p+1   → st[1]
// p+2   → st[2]
// (p+1)->score → st[1].score → 84
```

## PART 4: 자주 나오는 함수/패턴

### 4-1. 재귀함수

```c
int f(int n) {
    if (n <= 1) return 1;
    return n * f(n-1);
}
// f(5) = 5 * 4 * 3 * 2 * 1 = 120 (팩토리얼)
```

### 4-2. swap 함수 (Call by Reference)

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int x = 10, y = 20;
swap(&x, &y);   // x=20, y=10
```

### 4-3. 연산자 우선순위 (시험 함정!)

| 우선순위 | 연산자 | 설명 |
|----------|--------|------|
| 1 | `()` `[]` `->` `.` | 괄호, 배열, 멤버접근 |
| 2 | `!` `~` `++` `--` `*`(역참조) `&`(주소) | 단항 연산자 |
| 3 | `*` `/` `%` | 산술 (곱/나눗셈) |
| 4 | `+` `-` | 산술 (덧/뺄셈) |
| 5 | `<<` `>>` | 시프트 |
| 6 | `<` `<=` `>` `>=` | 관계 |
| 7 | `==` `!=` | 동등 |
| 8 | `&` `^` `\|` | 비트 AND, XOR, OR |
| 9 | `&&` `\|\|` | 논리 AND, OR |
| 10 | `? :` | 삼항 |
| 11 | `=` `+=` `-=` 등 | 대입 |

### 4-4. printf 서식 지정자

| 서식 | 의미 | 예시 |
|------|------|------|
| `%d` | 정수 (10진수) | `printf("%d", 10)` → 10 |
| `%c` | 문자 1개 | `printf("%c", 65)` → A |
| `%s` | 문자열 | `printf("%s", "Hi")` → Hi |
| `%f` | 실수 | `printf("%.2f", 3.14)` → 3.14 |
| `%o` | 8진수 | `printf("%o", 10)` → 12 |
| `%x` | 16진수 | `printf("%x", 255)` → ff |

### 문제 4 (스택) ★★★★★

```c
#include <stdio.h>
#define MAX 10

int stack[MAX];
int top = -1;

void push(int num) { stack[++top] = num; }
int pop() { return stack[top--]; }
int isEmpty() { return top == -1; }

int main() {
    push(1); push(2); push(3);
    printf("%d", pop());
    push(4); push(5);
    printf("%d", pop());
    printf("%d", pop());
    push(6);
    while (!isEmpty()) printf("%d", pop());
    return 0;
}
```

**트레이싱 메모:**

### 문제 7 (포인터 + 증감 연산) ★★★★

```c
#include <stdio.h>
int main() {
    int a[] = {10, 20, 30, 40};
    int *p = a + 1;

    printf("%d ", *p--);
    printf("%d ", ++*p);
    printf("%d ", *(p += 2));
    printf("%d ", (*p)--);
    printf("%d", *p + a[0]);
    return 0;
}
```

**트레이싱 메모:**
```
*p--     → 지금 *p 를 출력한 뒤 p 를 한 칸 앞으로
++*p     → *p 값을 1 늘린 뒤 출력
*(p+=2)  → p 를 두 칸 뒤로 옮긴 뒤 *p 출력
(*p)--   → 지금 *p 를 출력한 뒤 값을 1 줄임
*p+a[0]  → 현재 *p 와 a[0] 의 합

p 위치:  a[1] → a[___] → a[___]
배열:    {___, ___, ___, ___}

출력: _______________
```

## PART 6: 정답 & 해설

<details>

### 문제 1 정답
```
THON
O
S
9
```
- `s + 2`: 세 번째 글자부터 끝까지 → THON
- `*(s + 4)`: 다섯 번째 글자 'O'
- `*s + 3`: 'P'(ASCII 80) + 3 = 83 = **'S'** — `*(s+3)`('H')과 헷갈리지 말 것
- `*(s + 1) - *s`: 'Y'(89) − 'P'(80) = **9** (%d 라 숫자로 출력)

### 문제 2 정답
```
fall fall fall
1
```
- `save` 는 매번 같은 전역 배열 `buf` 의 주소를 돌려준다. a · b · c 는 모두 같은 곳을 가리키고, 마지막에 복사한 "fall" 만 남는다.
- `a == c` 는 주소 비교 → 같은 주소이므로 **1**

### 문제 3 정답
```
90
```
- `(p+2)->sum` = s[2].kor + s[0].eng = 85 + 80 = **165**
- `p->sum` = s[1].kor + s[2].sum = 90 + 165 = **255**
- 출력: 255 − 165 = **90**

### 문제 4 정답
```
354621
```
1. push 1, 2, 3 → [1,2,3]
2. pop()=**3** → [1,2]
3. push 4, 5 → [1,2,4,5]
4. pop()=**5**, pop()=**4** → [1,2]
5. push 6 → [1,2,6]
6. 비울 때까지: **6, 2, 1**

### 문제 5 정답
```
80,20
```
- 3열로 끊어 보면 p[0] = [10,20,30], p[1] = [40,50,60]
- `*(p[0]+2)` = 30, `*(p[1]+1)` = 50 → **80**
- `**(p+1)` = p[1][0] = 40, `*(*p+1)` = p[0][1] = 20 → **20**

### 문제 6 정답
```
975975
```

### 문제 7 정답
```
20 11 30 30 40
```
1. `*p--`: a[1]=**20** 출력, p → a[0]
2. `++*p`: a[0] 을 10→11, **11** 출력

4. `(*p)--`: **30** 출력 후 a[2] 를 29 로
5. `*p + a[0]`: 29 + 11 = **40**
