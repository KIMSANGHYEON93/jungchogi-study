## A. 데이터베이스 — 16문제

### X001. 관계대수 연산자 중 조건에 맞는 행을 고르는 연산(①), 원하는 열만 고르는 연산(②), 기호를 쓰시오.

<details><summary>정답</summary>

- ① **셀렉트(Select) σ** — 행(튜플) 선택
- ② **프로젝트(Project) π** — 열(속성) 선택
- 그 밖에 조인 ⋈, 디비전 ÷ 가 순수 관계 연산자다

</details>

### X002. 관계대수의 디비전(÷) 연산 결과를 설명하시오: R(A, B) ÷ S(B)

<details><summary>정답</summary>

- S 의 **모든 B 값과 짝을 이루는 R 의 A 값**만 남긴다
- 예: R = {(1,x),(1,y),(2,x)}, S = {x, y} → 결과 **{1}** (2 는 y 와 짝이 없다)

</details>

### X003. 데이터베이스 스키마 3계층을 쓰고 각각을 설명하시오.

<details><summary>정답</summary>

- **외부 스키마**: 사용자 · 응용 프로그램마다 보는 논리 구조(서브 스키마, 뷰)
- **개념 스키마**: 조직 전체의 논리 구조 — 개체 · 관계 · 제약조건 · 접근 권한
- **내부 스키마**: 물리적 저장 구조 — 레코드 형식 · 인덱스 · 저장 순서

</details>

### X004. 트랜잭션의 상태 5가지를 쓰시오.

<details><summary>정답</summary>

**활동(Active) → 부분 완료(Partially Committed) → 완료(Committed)**, 실패 시 **실패(Failed) → 철회(Aborted)**

- 부분 완료: 마지막 연산까지 실행했지만 COMMIT 전
- 철회: ROLLBACK 으로 실행 전 상태로 되돌림

</details>

### X005. 회복 기법 중 트랜잭션이 완료(COMMIT)될 때까지 DB 변경을 미루는 기법(①)과 즉시 반영하는 기법(②)을 쓰시오.

<details><summary>정답</summary>

- ① **지연 갱신(Deferred Update)** — 장애 시 UNDO 가 필요 없고 REDO 만 한다
- ② **즉시 갱신(Immediate Update)** — 장애 시 UNDO · REDO 모두 필요
- 그 밖에 **검사점(Checkpoint)**, **그림자 페이징(Shadow Paging)** 기법이 있다

</details>

### X006. 병행 제어 기법 중 트랜잭션이 데이터에 접근하기 전에 잠금을 걸고, 잠금 획득 단계와 해제 단계를 나누는 규약은?

<details><summary>정답</summary>

**2단계 로킹(2PL, Two-Phase Locking)** — 확장 단계(잠금만 획득) → 축소 단계(해제만)

- 직렬 가능성을 보장하지만 교착상태가 생길 수 있다
- 다른 병행 제어 기법: 타임스탬프 순서, 낙관적 검증, 다중 버전(MVCC)

</details>

### X007. 로킹 단위(Locking Granularity)가 클 때와 작을 때의 특징을 쓰시오.

<details><summary>정답</summary>

- **단위가 크면**: 잠금 수가 적어 관리가 쉽지만 **병행성이 낮다**
- **단위가 작으면**: 병행성이 높지만 잠금 수가 많아 **관리 오버헤드가 크다**

</details>

### X008. 분산 데이터베이스의 투명성 4가지를 쓰시오.

<details><summary>정답</summary>

- **위치 투명성**: 데이터가 어느 지역에 있는지 몰라도 된다
- **중복(복제) 투명성**: 여러 곳에 복제되어 있어도 하나처럼 쓴다
- **병행 투명성**: 여러 트랜잭션이 동시에 실행돼도 결과가 일관된다
- **장애 투명성**: 일부 지역 장애가 나도 무결성이 지켜진다

</details>

### X009. 다음 SQL 집합 연산자의 차이를 쓰시오: UNION, UNION ALL, INTERSECT, EXCEPT(MINUS)

<details><summary>정답</summary>

- **UNION**: 합집합, 중복 행 제거
- **UNION ALL**: 합집합, 중복 행 유지
- **INTERSECT**: 교집합
- **EXCEPT / MINUS**: 앞 결과에서 뒤 결과를 뺀 차집합

</details>

### X010. 학생(student) 테이블에 VARCHAR(20) 타입의 주소(addr) 열을 추가하는 SQL문을 쓰시오.

<details><summary>정답</summary>

```sql
ALTER TABLE student ADD addr VARCHAR(20);
```

- 열 수정은 `ALTER TABLE ... MODIFY`(또는 ALTER COLUMN), 삭제는 `ALTER TABLE ... DROP COLUMN`

</details>

### X011. 이름(name)이 '김'으로 시작하는 학생을 조회하는 WHERE 절을 쓰고, `_` 와 `%` 의 차이를 설명하시오.

<details><summary>정답</summary>

```sql
WHERE name LIKE '김%'
```

- `%`: 0개 이상의 아무 문자
- `_`: 정확히 1개의 아무 문자 (예: `'김__'` 은 '김'으로 시작하는 세 글자)

</details>

### X012. 서브쿼리에서 IN 과 EXISTS 의 차이를 쓰시오.

<details><summary>정답</summary>

- **IN**: 서브쿼리 결과 값 목록 안에 비교 값이 있는지 본다
- **EXISTS**: 서브쿼리 결과 **행이 하나라도 있는지(참/거짓)** 만 본다 — 보통 바깥 행과 연관된(상관) 서브쿼리로 쓴다

</details>

### X013. SQL 명령을 DDL, DML, DCL 로 분류하시오: CREATE, SELECT, GRANT, ALTER, UPDATE, REVOKE, DROP, INSERT

<details><summary>정답</summary>

- **DDL**(정의): CREATE, ALTER, DROP (+ TRUNCATE)
- **DML**(조작): SELECT, INSERT, UPDATE (+ DELETE)
- **DCL**(제어): GRANT, REVOKE (+ COMMIT, ROLLBACK 을 TCL 로 따로 나누기도 한다)

</details>

### X014. 테이블 파티셔닝(Partitioning) 유형 3가지를 쓰시오.

<details><summary>정답</summary>

- **범위(Range)**: 날짜 · 숫자 구간으로 나눔
- **해시(Hash)**: 해시 함수 값으로 고르게 나눔
- **목록(List)**: 지정한 값 목록(지역 코드 등)으로 나눔
- 둘 이상을 섞은 **조합(Composite)** 분할도 있다

</details>

### X015. 옵티마이저의 두 가지 유형을 쓰고 차이를 설명하시오.

<details><summary>정답</summary>

- **규칙 기반(RBO)**: 미리 정한 우선순위 규칙으로 실행 계획을 고른다
- **비용 기반(CBO)**: 통계 정보로 예상 비용(I/O · CPU)이 가장 적은 계획을 고른다

</details>

### X016. NoSQL 데이터 모델 4가지를 쓰시오.

<details><summary>정답</summary>

- **키-값(Key-Value)**: Redis, DynamoDB
- **문서(Document)**: MongoDB
- **열 패밀리(Column Family)**: Cassandra, HBase

</details>

### X055. CSRF(Cross-Site Request Forgery)를 설명하시오.

<details><summary>정답</summary>

### X056. 다음 공격을 설명하시오: 스니핑(Sniffing), 스푸핑(Spoofing)

<details><summary>정답</summary>

- **스니핑**: 네트워크에 흐르는 패킷을 **몰래 엿듣는** 수동적 공격
- **스푸핑**: IP · MAC · ARP · DNS 등을 **속여** 다른 사람인 것처럼 하는 공격

</details>

### X057. 피싱, 파밍, 스미싱의 차이를 쓰시오.

<details><summary>정답</summary>

- **피싱**: 가짜 메일 · 사이트로 개인정보를 낚는다
- **파밍**: DNS · hosts 를 변조해 **정상 주소를 입력해도** 가짜 사이트로 보낸다
- **스미싱**: **문자 메시지(SMS)** 의 링크로 악성 앱 설치 · 정보 탈취

</details>

### X058. APT(Advanced Persistent Threat) 공격이란?

<details><summary>정답</summary>

특정 조직을 노려 **오랜 기간 지속적으로** 침투 · 잠복하며 정보를 빼내는 지능형 지속 위협 — 사회공학 · 제로데이 취약점 등을 조합한다

</details>

### X059. 바이러스, 웜, 트로이 목마의 차이를 쓰시오.

<details><summary>정답</summary>

- **바이러스**: 다른 프로그램에 **기생**해 감염 · 실행돼야 퍼진다
- **웜**: **스스로 복제**해 네트워크로 퍼진다
- **트로이 목마**: 정상 프로그램으로 **위장**하며 자기 복제는 하지 않는다

</details>
