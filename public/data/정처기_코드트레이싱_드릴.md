## Part 1. C언어 (10문제)

### C-01. 포인터 기본

```c
#include <stdio.h>
int main() {
    int x = 4, y = 9;
    int *p = &y;
    *p = *p - x;
    p = &x;
    *p = *p * y;
    printf("%d %d", x, y);
    return 0;
}
```

<details>
<summary>정답 및 풀이</summary>

```
x=4, y=9, p=&y
*p = *p - x → y = 9 - 4 = 5
p = &x      → p 가 x 를 가리킴
*p = *p * y → x = 4 * 5 = 20   (y 는 이미 5)

출력: 20 5
```
**함정**: `*p` 는 "지금 p 가 가리키는 변수"다. p 를 옮긴 뒤에는 다른 변수를 바꾼다
</details>

### C-02. 후위/전위 증감

```c
#include <stdio.h>
int main() {
    int a = 3, b = 7;
    int c = ++a * b--;
    int d = a-- + --b;
    printf("%d %d %d %d", a, b, c, d);
    return 0;
}
```

<details>
<summary>정답 및 풀이</summary>

```
a=3, b=7
c = ++a * b--  → a 를 4 로 올린 뒤 4 * 7(b 는 쓰고 나서 6) = 28
d = a-- + --b  → 4(a 는 쓰고 나서 3) + 5(b 를 5 로 내린 뒤) = 9
a=3, b=5

출력: 3 5 28 9
```
**함정**: 전위(++a)는 바꾼 값을, 후위(b--)는 바꾸기 전 값을 식에 쓴다
</details>

### C-03. 배열과 포인터

```c
#include <stdio.h>
int main() {
    int a[] = {5, 10, 15, 20, 25};
    int *p = a + 2;
    printf("%d ", *p);
    printf("%d ", *(p - 2) + p[1]);
    printf("%d", *(a + 4) - *p);
    return 0;
}
```

<details>
<summary>정답 및 풀이</summary>

```
p = a + 2 → a[2] = 15
*(p - 2) + p[1] = a[0] + a[3] = 5 + 20 = 25
*(a + 4) - *p   = a[4] - a[2] = 25 - 15 = 10

출력: 15 25 10
```
**함정**: `p[1]` 은 `*(p + 1)` 과 같다 — p 기준으로 한 칸 뒤(a[3])
</details>

### C-04. 재귀함수

```c
#include <stdio.h>
int g(int n) {
    if (n <= 1) return 2;
    return g(n - 2) + n;
}
int main() {
    printf("%d", g(7));
    return 0;
}
```

<details>
<summary>정답 및 풀이</summary>

```
g(7) = g(5) + 7
g(5) = g(3) + 5
g(3) = g(1) + 3
g(1) = 2
→ g(3)=5, g(5)=10, g(7)=17

출력: 17
```
**함정**: 기저 조건의 반환값(2)부터 거꾸로 올라오며 더한다
</details>

### C-05. 2차원 배열

```c
#include <stdio.h>
int main() {
    int m[2][4] = {{1, 2, 3, 4}, {5, 6, 7, 8}};
    int i, j, sum = 0;
    for (i = 0; i < 2; i++)
        for (j = i; j < 4; j += 2)
            sum += m[i][j];
    printf("%d %d", sum, m[1][3] - m[0][1]);
    return 0;
}
```

<details>
<summary>정답 및 풀이</summary>

```
i=0: j=0, 2 → m[0][0] + m[0][2] = 1 + 3 = 4
i=1: j=1, 3 → m[1][1] + m[1][3] = 6 + 8 = 14
sum = 18
m[1][3] - m[0][1] = 8 - 2 = 6

출력: 18 6
```
**함정**: 안쪽 반복의 시작값이 바깥 변수 i 다 — 행마다 시작 열이 다르다
</details>

### C-07. swap 함수 (값 전달 vs 주소 전달)

```c
#include <stdio.h>
void f(int a, int *b) {
    a = a * 2;
    *b = *b * 2;
}
int main() {
    int x = 3, y = 5;
    f(x, &y);
    f(y, &x);
    printf("%d %d", x, y);
    return 0;
}
```

<details>
<summary>정답 및 풀이</summary>

```
f(x, &y): a 는 x 의 복사본(바뀌어도 x 는 그대로), *b 로 y = 10
f(y, &x): a 는 y 의 복사본, *b 로 x = 3 * 2 = 6

출력: 6 10
```
**함정**: 값으로 받은 매개변수를 바꿔도 원본은 그대로다
</details>

### C-08. 구조체

```c
#include <stdio.h>
struct pt {
    int x, y;
};
int main() {
    struct pt a[3] = {{1, 2}, {3, 4}, {5, 6}};
    struct pt *p = &a[1];
    p->x += a[0].y;
    (p + 1)->y -= p->x;
    printf("%d %d %d", a[1].x, a[2].y, (*p).y);
    return 0;
}
```

<details>
<summary>정답 및 풀이</summary>

```
p = &a[1]
p->x += a[0].y      → a[1].x = 3 + 2 = 5
(p + 1)->y -= p->x  → a[2].y = 6 - 5 = 1
(*p).y = a[1].y = 4

출력: 5 1 4
```
**함정**: `p->y` 와 `(*p).y` 는 같은 뜻이다
</details>

### C-09. static 변수

```c
#include <stdio.h>
int count() {
    static int n = 0;
    int k = 0;
    n += 2;
    k += 2;
    return n + k;
}
int main() {
    int i, s = 0;
    for (i = 0; i < 3; i++) s += count();
    printf("%d", s);
    return 0;
}
```

<details>
<summary>정답 및 풀이</summary>

```
static n 은 호출이 끝나도 값이 남고, k 는 매번 0 에서 시작
1회: n=2, k=2 → 4
2회: n=4, k=2 → 6
3회: n=6, k=2 → 8
s = 4 + 6 + 8 = 18

출력: 18
```
**함정**: static 지역 변수의 초기화는 처음 한 번만 일어난다
</details>

### C-10. 비트 연산

<summary>정답 및 풀이</summary>

```
13 = 1101, 6 = 0110
```

### J-04. 추상 클래스

```java
abstract class Shape {
    abstract double area();
    String desc() { return "area=" + (int) area(); }
}
class Tri extends Shape {
    int b, h;
    Tri(int b, int h) { this.b = b; this.h = h; }
    double area() { return b * h / 2.0; }
}
public class Main {
    public static void main(String[] args) {
        Shape s = new Tri(5, 3);
        System.out.println(s.desc() + " " + s.area());
    }
}
```

<details>
<summary>정답 및 풀이</summary>

```
area() = 5 * 3 / 2.0 = 7.5
desc() 는 (int) 로 소수점을 버림 → "area=7"
s.area() 는 double 그대로 → 7.5

출력: area=7 7.5
```
**함정**: `/ 2.0` 처럼 실수가 섞이면 실수 나눗셈, `(int)` 는 반올림이 아니라 버림
</details>

### J-10. 싱글톤 패턴

```java
class Config {
    private static Config inst;
    private int v = 0;
    private Config() {}
    static Config get() {
        if (inst == null) inst = new Config();
        return inst;
    }
    Config add(int n) { v += n; return this; }
    int value() { return v; }
}
public class Main {
    public static void main(String[] args) {
        Config.get().add(3).add(4);
        Config c = Config.get();
        c.add(5);
        System.out.println(Config.get().value() + " " + (c == Config.get()));
    }
}
```

<details>
<summary>정답 및 풀이</summary>

```
get() 은 처음 한 번만 객체를 만들고 이후엔 같은 객체를 돌려준다
add 가 this 를 돌려주므로 이어서 호출 가능: 3 + 4 = 7
c.add(5) → 12
c 와 Config.get() 은 같은 객체 → true

출력: 12 true
```
**함정**: 생성자가 private 이라 밖에서 new 로 만들 수 없다
</details>

```python
        self.n += 2
    def show(self):
        return super().show() + 1

print(A().show(), B().show())
```

<details>
<summary>정답 및 풀이</summary>

```
A(): n = 1 → show() = 10
B(): super().__init__() 로 n = 1, 그다음 n = 3
B().show() = super().show()(3*10) + 1 = 31

출력: 10 31
```
**함정**: super().show() 안의 self.n 은 B 객체의 n(3)이다
</details>

### P-10. 중첩 반복문 + 조건

```python
        total += i * j
```

```
total = 25

출력: 25
```
**함정**: continue 는 안쪽 반복의 다음 j 로 넘어간다 (바깥 반복은 계속)

### S-01. GROUP BY + HAVING

```
테이블: 주문(고객, 상품, 금액)
| 고객 | 상품 | 금액 |
|------|------|------|
| 김 | 펜 | 300 |
| 이 | 책 | 1200 |
| 김 | 책 | 900 |
| 박 | 컵 | 500 |
| 이 | 펜 | 300 |
| 김 | 컵 | 600 |
```

```sql
SELECT 고객, COUNT(*) AS 건수, SUM(금액) AS 합계
FROM 주문
GROUP BY 고객
HAVING SUM(금액) >= 1000
ORDER BY 합계 DESC;
```

<details>
<summary>정답 및 풀이</summary>

```
① GROUP BY 고객:
   김: 300 + 900 + 600 = 1800 (3건)
   이: 1200 + 300 = 1500 (2건)
   박: 500 (1건)
② HAVING 합계 >= 1000 → 박 제외
③ 합계 내림차순

결과:
| 고객 | 건수 | 합계 |
|------|------|------|
| 김 | 3 | 1800 |
| 이 | 2 | 1500 |
```
**함정**: 집계 함수로 거르는 조건은 WHERE 가 아니라 HAVING
</details>

### S-02. JOIN

```
테이블: 학생(학번, 이름, 학과코드)
| 학번 | 이름 | 학과코드 |
|------|------|------|
| 1 | 김 | 10 |
| 2 | 이 | 20 |
| 3 | 박 | 30 |

테이블: 학과(학과코드, 학과명)
```

```sql
SELECT 학생.이름, 학과.학과명
FROM 학생 JOIN 학과 ON 학생.학과코드 = 학과.학과코드

```

<details>
<summary>정답 및 풀이</summary>

```
INNER JOIN 은 양쪽에 짝이 있는 행만 남긴다
박(학과코드 30)은 학과 테이블에 30 이 없어 빠진다

결과:
| 이름 | 학과명 |
|------|------|
| 김 | 컴공 |
| 이 | 전자 |
```
**함정**: 짝이 없는 행까지 남기려면 LEFT JOIN
</details>

```
③ 급여 내림차순

| 이름 |
|------|

| 정 |
```

**함정**: 서브쿼리는 전체 평균이 아니라 영업 부서 평균이다 — WHERE 조건을 놓치지 말 것

### S-06. UPDATE + DELETE


```sql
UPDATE 재고 SET 수량 = 수량 + 10 WHERE 수량 < 5;
```

```
|------|------|
| A | 5 |
| B | 10 |
| C | 12 |
```
**함정**: 앞 문장의 결과가 다음 문장의 조건에 그대로 영향을 준다

### S-08. GRANT / REVOKE

```
다음 빈칸을 채우시오:

(1) 사용자 'lee'에게 주문 테이블의 UPDATE 권한을 주되, lee 가 그 권한을 다른 사용자에게 다시 줄 수 있게:
    ___ UPDATE ON 주문 TO lee ___ ___ ___;

(2) 사용자 'lee'에게서 주문 테이블의 UPDATE 권한을 회수하되, lee 가 다른 사용자에게 준 권한까지 함께 회수:
```

```sql
REVOKE UPDATE ON 주문 FROM lee CASCADE;
```

**암기**: GRANT 는 TO + WITH GRANT OPTION, REVOKE 는 FROM + CASCADE

### S-09. INNER JOIN + GROUP BY

```
테이블: 고객(고객ID, 이름)
| 고객ID | 이름 |
|------|------|
| 1 | 김 |
| 2 | 이 |
| 3 | 박 |

테이블: 주문(주문ID, 고객ID, 금액)
| 주문ID | 고객ID | 금액 |
|------|------|------|
| 1 | 1 | 100 |
| 2 | 2 | 300 |
| 3 | 1 | 250 |
| 4 | 2 | 50 |
| 5 | 1 | 50 |
```

```sql
SELECT 고객.이름, COUNT(*) AS 주문수, SUM(주문.금액) AS 합계
FROM 고객 JOIN 주문 ON 고객.고객ID = 주문.고객ID
GROUP BY 고객.이름
HAVING COUNT(*) >= 2
ORDER BY 합계 DESC;
```

<details>
<summary>정답 및 풀이</summary>

```
① JOIN: 주문마다 고객 이름을 붙인다 (박은 주문이 없어 빠짐)
② 김: 100 + 250 + 50 = 400 (3건), 이: 300 + 50 = 350 (2건)
③ HAVING 2건 이상 → 둘 다 남음, 합계 내림차순

결과:
| 이름 | 주문수 | 합계 |
|------|------|------|
| 김 | 3 | 400 |
| 이 | 2 | 350 |
```
**함정**: INNER JOIN 에서 주문이 없는 고객은 아예 그룹에 들어오지 않는다
</details>

### S-10. IS NULL + COALESCE

```
테이블: 직원(이름, 보너스)
| 이름 | 보너스 |
|------|------|
| 김 | 100 |
| 이 | NULL |
| 박 | 0 |
| 최 | NULL |
```

```sql
SELECT 이름, COALESCE(보너스, -1) AS 보너스
FROM 직원
WHERE 보너스 IS NULL OR 보너스 = 0
ORDER BY 이름;
```

<details>
<summary>정답 및 풀이</summary>

```
보너스 IS NULL → 이, 최 / 보너스 = 0 → 박
COALESCE(보너스, -1): NULL 이면 -1 로 바꿔 보여 줌
이름 오름차순: 박, 이, 최

결과:
| 이름 | 보너스 |
|------|------|
| 박 | 0 |
| 이 | -1 |
| 최 | -1 |
```
**함정**: NULL 은 = 로 비교할 수 없다 — IS NULL. 0 과 NULL 은 다르다
</details>

## Part 5. 함정 유형 TOP 10 총정리

```
┌──────────────────────────────────────────────────────┐
│  ★ 시험장에서 가장 많이 틀리는 함정 10가지 ★        │
├──────────────────────────────────────────────────────┤
│                                                      │
│  1. a++ vs ++a                                       │
│     → a++ = 현재값 사용 후 증가                      │
│     → ++a = 증가 후 사용                             │
│                                                      │
│  2. *p+2 vs *(p+2)                                   │
│     → *p+2 = 값에 +2                                 │
│     → *(p+2) = 주소 2칸 이동 후 역참조               │
│                                                      │
│  3. 변수=부모, 메서드=자식 (Java 다형성)             │
│     → A obj = new B();                               │
│     → obj.변수 = A것, obj.메서드() = B것             │
│                                                      │
│  4. == vs equals() (Java String)                     │
│     → == 참조비교, equals() 값비교                   │
│     → 리터럴끼리는 == 도 true (Pool 공유)            │
│                                                      │
│  5. substring(s,e) / 슬라이싱[s:e]                   │
│     → e는 미포함! (s부터 e-1까지)                    │
│                                                      │
│  6. range(n) / range(s,e)                            │
│     → range(5) = 0,1,2,3,4 (0부터, n 미포함)        │
│                                                      │
│  7. COUNT(*) vs COUNT(컬럼)                          │
│     → COUNT(*) = NULL 포함                           │
│     → COUNT(컬럼) = NULL 제외                        │
│                                                      │
│  8. WHERE vs HAVING                                  │
│     → WHERE = 그룹 전 필터 (집계함수 X)              │
│     → HAVING = 그룹 후 필터 (집계함수 O)             │
│                                                      │
│  9. > vs >= (초과 vs 이상)                           │
│     → WHERE 급여 > 400 → 400 미포함!                 │
│     → WHERE 급여 >= 400 → 400 포함                   │
│                                                      │
│  10. = NULL (X) → IS NULL (O)                        │
│      → NULL 비교는 반드시 IS NULL / IS NOT NULL       │
│                                                      │
└──────────────────────────────────────────────────────┘
```
