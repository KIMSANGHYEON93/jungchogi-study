#include <stdio.h>

int main() {
    char s[] = "ALGORITHM";
    int i, n = strlen(s);
    for (i = 0; i < n / 2; i++) {
        char t = s[i];
        s[i] = s[n - 1 - i];
        s[n - 1 - i] = t;
    }
    printf("%s %d %c\n", s, n, s[n / 2]);
    return 0;
}
```

```

양 끝부터 바꿔 문자열을 뒤집는다 → MHTIROGLA
가운데 s[4] 는 그대로: M(0) H(1) T(2) I(3) R(4) → R

### 문제 5. 다음 Java 프로그램의 출력 결과를 쓰시오. (5점)

```java
public class Main {
    static int test(int n) {
        try {
            System.out.print("T");
            if (n == 0) throw new ArithmeticException();
            return 10 / n;
        } catch (ArithmeticException e) {
            System.out.print("C");
            return -1;
        } finally {
            System.out.print("F");
        }
    }
    public static void main(String[] args) {
        int a = test(5);
        int b = test(0);
        System.out.println(" " + (a + b));
    }
}
```

답:

<details><summary>정답 확인</summary>

**정답: `TFTCF 1`**

```
finally 는 return 이 있어도 **항상** 실행된다
test(5): "T" → return 2 직전에 finally "F"           → a = 2
test(0): "T" → 예외 → catch "C" → finally "F"        → b = -1
" " + (2 + (-1)) → " 1"
```

</details>

### 문제 10. 다음 Java 프로그램의 출력 결과를 쓰시오. (5점)

```java
class Counter {
    static int total = 0;
    int count = 0;
    void add() { count++; total++; }
}
public class Main {
    public static void main(String[] args) {
        Counter c1 = new Counter();
        Counter c2 = new Counter();
        c1.add();
        c1.add();
        c2.add();
        c2 = c1;
        c2.add();
        System.out.println(c1.count + " " + c2.count + " " + Counter.total);
    }
}
```

답:

<details><summary>정답 확인</summary>

**정답: `3 3 4`**

```
c1.add() 두 번 → c1.count = 2, total = 2
c2.add()       → c2.count = 1, total = 3
c2 = c1        → c2 도 c1 과 같은 객체를 가리킨다
c2.add()       → 그 객체의 count = 3, total = 4
c1.count = c2.count = 3
```

</details>

### 문제 13. 다음 Python 프로그램의 출력 결과를 쓰시오. (5점)

```python
def rev(s):
    if len(s) <= 1:
        return s
    return rev(s[1:]) + s[0]

def count(s, ch):
    if not s:
        return 0
    return (1 if s[0] == ch else 0) + count(s[1:], ch)

w = "banana"
print(rev(w))
print(count(w, "a") * len(w))
```

답:

<details><summary>정답 확인</summary>

**정답:**

```
ananab
18
```

```
rev: 첫 글자를 맨 뒤로 보내며 나머지를 다시 뒤집는다 → "ananab"
count: 첫 글자가 ch 면 1 을 더하며 나머지로 재귀 → "a" 는 3 개
3 * len("banana")(6) = 18
```

</details>

### 문제 19. 다음 Python 프로그램의 출력 결과를 쓰시오. (5점)

```python
class Base:
    count = 0
    def __init__(self, v):
        self.v = v
        Base.count += 1
    def calc(self):
        return self.v * 2

class Child(Base):
    def __init__(self, v, w):
        super().__init__(v)
        self.w = w
    def calc(self):
        return super().calc() + self.w

objs = [Base(3), Child(3, 4), Child(1, 10)]
print([o.calc() for o in objs])
print(Base.count)
```

답:

<details><summary>정답 확인</summary>

**정답:**

```
[6, 10, 12]
3
```

```
Base(3).calc()     = 3 * 2 = 6
Child(3, 4).calc() = super().calc()(6) + 4 = 10
Child(1, 10).calc()= 2 + 10 = 12
Child 생성자도 super().__init__ 을 부르므로 count 는 세 번 증가 → 3
```

</details>
